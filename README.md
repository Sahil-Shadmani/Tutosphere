# 🎓 TutoSphere

A responsive online tutoring platform frontend built to help students explore subjects and discover flexible learning options.

## 🌐 Live Demo

[Visit TutoSphere](https://tutosphere.vercel.app/)

## 🚀 Features

-  Reusable Components.
-  Fully Responsive Layout.
-  Easy Navigation.
-  Subject exploration section.
-  How It Works section.
-  Interactive testimonial carousel.
-  Contact section.

## 🛠️ Tech Stack

-  React.js
-  Vite
-  Tailwind CSS
-  React Icons
-  React Slick
